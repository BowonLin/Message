每次到了幹部交接大會的時候，秘書組會上傳幹部留言板給續任和離任幹部一些心裡話，由於是google form做的東西，生成回覆內容的 excel 最左邊一定是誰寫的，往右是寫給誰的，內容則是再下一格，那麼如果他留言的人很多，格子會一，往右延伸，每個人寫的信數不一樣，再加上秘書組要做留言手冊，要收集「這個人要收到的留言」，因為同一個人可能被很多不同人寫，在整理丟到 word 上很花時間和精力，所以我做了這個程式碼

要使用我的程式碼很簡單，先把所有幹部留言集中在一個 excel 檔，並把無關緊要的內容刪掉
最上面要有個欄位寫「your_name」、「to_whom」、「say_it」
「your_name」是指誰寫的留言板
「to_whom」是指要寫給誰
「say_it」是指要向他說什麼
最後整理成這個網頁的「letter.xlsx」那樣

絕對路徑自己改，上面名單的需要修改成你們這屆的名單，再接著用我的程式碼整理資料

執行後的樣子會是另一個檔案「實力.xlsx」
